# Лабораторная работа №1

## Перемножение квадратных матриц на C++ с автоматической верификацией на Python

Программа предназначена для перемножения двух квадратных матриц произвольного размера. Реализация выполнена на языке C++. Для независимой проверки корректности вычислений используется Python и библиотека NumPy.

Проект позволяет исследовать зависимость времени выполнения, объема задачи и объема используемой памяти от размера входных матриц.

## Исследование производительности

Для исследования производительности используется массив заранее заданных размеров квадратных матриц: 100, 200, 400, 600, 800 и 1000.

Алгоритм работы:
1. Для каждого размера создаются две матрицы A и B, которые заполняются псевдослучайными вещественными числами типа `double`. Затем выполняется их последовательное перемножение.
2. Во время вычислений измеряется время выполнения операции, рассчитывается количество элементов, количество итераций внутреннего цикла и объём памяти.
3. Полученные результаты для каждого размера записываются в файл `results.txt`, что позволяет исследовать зависимость от размера входных данных.

Также во время выполнения программы, при размере матриц равном 100x100, данные матриц записываются в файлы `A.txt`,`B.txt` и `C_cpp.txt`


## Результаты исследования

В ходе эксперимента были выполнены последовательные перемножения квадратных матриц следующих размеров: 100×100, 200×200, 400×400, 600×600, 800×800 и 1000×1000.

**Используемые формулы**
1. Количество элементов матрицы:
```text
N = n²
```
2. Приблизительное количество операций при умножении матриц:
```text
FLOP = 2 · n³
```
3. Объём памяти для хранения трёх матриц A, B и C:
```text
M = (3 · n² · 8) / (1024 · 1024) МБ
```
**Обозначения:**
- `n` — размер стороны квадратной матрицы;
- `FLOP` — количество операций с плавающей запятой;
- `8` — размер одного элемента типа `double` в байтах;

## Верификация результатов

Для проверки корректности работы программы используется Python и библиотека NumPy.

Скрипт `verify.py` выполняет следующие действия:

1. Считывает исходные данные матрицы из файлов `A.txt` и `B.txt`.
2. Считывает результат, полученный программой на C++ из файла `C_cpp.txt`.
3. Вычисляет произведение матриц с помощью операции `A @ B`.
4. Сравнивает полученный результат с результатом C++.
5. Выводит сообщение об успешной верификации или несоответствии.
